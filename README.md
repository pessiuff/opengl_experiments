# OpenGL Experiments

Some OpenGL experiments that I made to learn about graphics programming. All of the experiments link to a static library called [shared](https://github.com/pessiuff/opengl_experiments/tree/main/shared).

## Experiments
- [triangle](https://github.com/pessiuff/opengl_experiments/tree/main/triangle): Simple triangle.
- [texture](https://github.com/pessiuff/opengl_experiments/tree/main/texture): Simple textured quad using EBO.
- [cube](https://github.com/pessiuff/opengl_experiments/tree/main/cube): Simple rotating textured cube.
